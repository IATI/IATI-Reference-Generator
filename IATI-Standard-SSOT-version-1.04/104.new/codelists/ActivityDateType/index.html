start-actual

The actual start date, such as date of first disbursement

end-actual

The actual end date, such as date of last disbursement

start-planned

The planned start date as recorded in project documentation. Can be date of signature of activity agreement or approval by relevant body

end-planned

The planned end date as recorded in project documentation
