actual¶

iati-activities/iati-activity/result/indicator/period/actual

This is the reference page for the XML element actual.

Definition¶

A record of the achieved result for this period.

Attributes¶

@value

The actual measure.

This value must be of type xsd:string.

Example Usage¶

Example usage of actual within period, in context of an indicator in a result element.

Example of a actual value of 11

  <result type="1" aggregation-status="1">
   <title>Result 1 title</title>
   <description>Result 1 description text</description>
   <indicator measure="1" ascending="1">
     <title>Indicator 1 title</title>
     <description>Indicator 1 description text</description>
     <baseline year="2012" value="10">
      <comment>Baseline comment text</comment>
     </baseline>
     <period>
      <period-start iso-date="2013-01-01" />
       <period-end iso-date="2013-03-31" />
       <target value="10">
        <comment>Target comment text</comment> 
       </target>
       <actual value="11">
        <comment>Actual comment text</comment> 
       </actual>
     </period>
   </indicator>
  </result>
