period-start¶

iati-activities/iati-activity/budget/period-start

This is the reference page for the XML element period-start.

Definition¶

The starting date for the budget period, in ISO 8601 format (e.g. 2010-04-01 for 1 April 2010). This element must be present.

Attributes¶

@iso-date

The ISO 8601 date.

This value must be of type xsd:date.

Example Usage¶

Example usage of period-start in context of budget element.

A date in ISO 8601 format (YYYY-MM-DD) for the period-start date of the reporting period is required:

  <budget type="1">
   <period-start iso-date="2014-01-01" />
   <period-end iso-date="2014-12-31" />
   <value currency="EUR" value-date="2014-01-01">3000</value>
  </budget>
